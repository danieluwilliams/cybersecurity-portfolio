# Hydroficient Project

Check out my dashboard: https://danieluwilliams.github.io/hydroficient-project/project-4/dashboard.html

This repository contains the Hydroficient MQTT/TLS security project work, including:

- certificate generation and mTLS testing
- MQTT publisher/subscriber examples
- dashboard and replay-defense experiments
- project 4 and project 6 related files

## Getting Started

1. Install dependencies:
   ```bash
   pip install paho-mqtt cryptography matplotlib
   ```
2. Generate certificates:
   ```bash
   python generate_certs.py
   ```
3. Run the MQTT examples as needed.

## Notes

This repository is intended for sharing and version control of the project work completed locally.
